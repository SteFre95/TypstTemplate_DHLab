# Typst-Template, DH Lab, University of Basel
A Typst-template for papers and theses from the Digital Humanities Lab of the University of Basel. Created and maintained by Stefan Freitag.

To get started, download every file except for ``Readme.md`` and upload them to your Typst project. Make sure ``unibas_dhlab_template.typ`` is set as the main ``.typ`` file.
